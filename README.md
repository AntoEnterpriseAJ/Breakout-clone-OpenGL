# Breakout Clone with OpenGL

A simple Breakout-style game built in C++ using OpenGL for rendering, GLFW for window/input management, and GLM for math. Inspired by the tutorials on [learnopengl.com](https://learnopengl.com/In-Practice/2D-Game/Breakout).

![image](https://github.com/user-attachments/assets/3165a59c-2889-4da5-bd17-f91adcd73e27)


## Features
- Classic Breakout mechanics (paddle, ball, bricks, multiple levels)
- Randomized power-ups (speed boost, paddle size increase, etc.)
- Post-processing effects (e.g., confusion, chaos)
- Simple particle system (ball trail)
- Text rendering via FreeType

## Requirements
- **All necessary libraries (GLAD, GLFW, GLM, FreeType) are bundled in this project for a plug-and-play setup**
